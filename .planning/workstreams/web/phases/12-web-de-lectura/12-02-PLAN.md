Contrato del servidor (cerrado en fase 10, NO se modifica): `GET /sync/pull?cursor=<string>&limit=<1..1000>` con `Authorization: Bearer <clave>` -> 200 `{ changes: [{ table, change_seq: string, payload }], nextCursor: string, hasMore: boolean }`; 400 por cursor/limit inválidos; 401 `{ error }`. `payload` = exactamente las columnas de `TABLE_SPEC[table]` (`web/api/_lib/spec.js:7-49`), epoch en segundos o null; una fila aparece una vez en su versión actual; borradas = fila completa con `deleted_at` (`web/api/sync/pull.js:11-18,55-59`). Las FKs son diferidas: un hijo puede llegar antes que su padre (`web/schema.sql:80-94`).

Contratos que este plan CREA (consumidos por 12-03..12-10):
- `pullAll({ base = '', key, cursor = '0', limit = 1000, signal, onPage }) -> Promise<{ rows, cursor }>`; `onPage({ page, rows, cursor, bytes, ms })`; lanza `HttpError { status, body, page, cursor }`.
- `emptyTables()` -> `{ recorridos, audios, artistas, obras, obra_artistas, paths, triggers }` (cada uno `Map<uuid, fila de lista blanca>`).
- `applyRows(tables, rows) -> { tables, read, discarded }` (no muta la entrada; `discarded` = filas con `deleted_at`).
