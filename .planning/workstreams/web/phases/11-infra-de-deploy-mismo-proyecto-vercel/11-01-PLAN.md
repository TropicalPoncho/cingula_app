         imprimir `SMOKE_API_KEY` ni `VERCEL_BYPASS` (ni con `set -x`).
       - Si falta `SMOKE_API_KEY`, imprimir `chequeo 2 salteado (SMOKE_API_KEY vacía): solo se
         verificó el ruteo` — no es falla.
       - Salida: `SMOKE OK <base>` y código 0 si todo lo corrido pasó; `SMOKE FAIL: <motivo con
         status y content-type recibidos>` y código 1 al primer chequeo que falle.
       - Solo GET. El script jamás hace POST (seguro contra producción; el push real lo prueba el
         celular en el plan 05).
       - Comentario de cabecera (español, 3-5 líneas) con uso, las dos variables y la regla "solo GET".
